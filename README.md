# cpurr 🐈

A cat that lives in your Omarchy bar. Busy computer, fast cat. Quiet computer, sleepy cat.

## Install

```sh
omarchy plugin add https://github.com/Deoxizn/omarchy-cpurr.git --enable
~/.config/omarchy/plugins/pizza.dirty.cpurr/setup/install.sh
```

Then restart the shell and add cpurr to the bar.

## Settings

- `size` — how big the cat is, in px. Default `32`. Keep it under your bar thickness.

Set it in the cpurr layout entry in `~/.config/omarchy/shell.json` (add `"size": 32`, or your value). It is not in the bar settings menu.
